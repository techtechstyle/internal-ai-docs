# Claude Code をはじめて使う

`🔵 SE` `⏱ 20分` `📶 初級`

このチュートリアルを終えると、[Claude Code](../glossary.md#claude-code) に日本語で質問し、コードについて説明を受けられるようになります。あわせて、ファイルの変更をお願いし、承認画面を確認しながら安全に任せる操作も体験します。

## はじめる前に

**必要なもの**

- セットアップ済みの Claude Code([Claude Code の個人環境をセットアップする](../how-to/setup-claude-code.md)を完了していること)
- 質問してよいリポジトリ(自分の作業用リポジトリ、または練習用の適当なフォルダ)

**前提知識**

- ターミナルの基本操作(`cd` でディレクトリを移動できる程度)
- Claude Code の全体像を先に知りたい方は[解説: Claude Code とは](../explanation/what-is-claude-code.md)を参照してください

## ステップ1: Claude Code を起動し、最初の質問をする

1. ターミナルでリポジトリのルートに移動し、Claude Code を起動します。

   ```bash
   cd <リポジトリのパス>
   claude
   ```

   入力を待つプロンプトが表示されます。

2. 日本語でプロジェクトについて質問します。

   ```text
   このプロジェクトが何をするものか、3行で教えて。
   ```

   出力は一例です。表現は実行のたびに変わりますが、次のような応答が返ります。

   ```text
   このプロジェクトは、社内向けの在庫管理システムです。
   主な機能は、入出庫の記録、在庫の検索、月次レポートの出力です。
   バックエンドには Node.js、フロントエンドには React を使用しています。
   ```

   次の要素が含まれていれば成功です。

   - [ ] プロジェクトの概要を説明する文章が返ってくる
   - [ ] 実際のファイルや機能を踏まえた説明になっている

## ステップ2: 質問を変えて、もう一度試す

もう一度、今度は具体的なファイルについて聞いてみましょう。

> **NOTE:** 質問のコツは、シニアエンジニアに聞くような質問をそのまま投げることです。例:「このAPIのリクエストはどこで検証される?」「なぜこのモジュールは分離されている?」

1. 同じ会話のまま、次の質問を入力します。

   ```text
   README.mdには何が書かれている?
   ```

   出力は一例です。表現は実行のたびに変わりますが、次のような応答が返ります。

   ```text
   README.mdには、プロジェクトの概要とセットアップ手順が書かれています。
   特に「開発環境の構築」の章に、必要なツールの一覧があります。
   ```

   次の要素が含まれていれば成功です。

   - [ ] README.md の内容に基づいた説明が返ってくる
   - [ ] 話題を変えても、ステップ1と同じ会話の中で応答が続く

## ステップ3: 簡単な作業を任せてみる

Claude Code に、実際にファイルを操作する作業を頼んでみましょう。

1. 次のように依頼します。

   ```text
   notes.mdというファイルを作って、「Claude Codeのチュートリアルを完了した」と書いて。
   ```

   出力は一例です。表現は実行のたびに変わりますが、次のような応答が返ります。

   ```text
   notes.mdを作成します。内容は次のとおりです。
   よろしいですか? (y/n)
   ```

   > **NOTE:** Claude Code はファイルを変更する前に、必ず承認を求めます。内容を確認してから `y` を入力してください。

   次の要素が含まれていれば成功です。

   - [ ] ファイル作成の承認を求める画面が表示される
   - [ ] `y` と入力すると、作成が完了したという応答が返る

2. 作成された内容を確認します。

   ```bash
   cat notes.md
   ```

   「Claude Codeのチュートリアルを完了した」と表示されれば、ファイルは正しく作成されています。

## 完了の確認

ターミナルで次のコマンドを実行します。

```bash
git status
```

次の状態になっていれば完了です。

- [ ] `claude` を起動でき、日本語の質問に応答が返ってくる
- [ ] 異なる2つの質問に対して、それぞれ内容に沿った応答が返ってきた
- [ ] `git status` の一覧に `notes.md` が表示される

この手順の操作はここまでです。作成した notes.md が不要な場合は、`rm notes.md` で削除して構いません。

## できたことの振り返り

このチュートリアルでは、次のことができるようになりました。

- Claude Code を起動し、日本語で質問して応答を受け取る
- 同じ会話の中で話題を変えながら、続けて質問する
- ファイル作成のような操作を、承認画面を確認しながら任せる

次は[リファレンス: コンテキスト操作コマンド一覧](../reference/context-commands.md)で、会話をリセットしたり要約したりするコマンドを確認しましょう。

## よくあるエラーと対処

### `claude: command not found` と表示される

- 原因: Claude Code が未インストールか、ターミナルの再起動が済んでいません。
- 対処: [Claude Code の個人環境をセットアップする](../how-to/setup-claude-code.md)の手順を確認してください。

### 質問しても英語で応答が返ってくる

- 原因: 応答言語をモデルが自動判定できていません。
- 対処: 質問文の末尾に「日本語で答えて」と付け加えてください。

### 承認画面で `y` と入力しても先に進まない

- 原因: 別の操作の承認待ちが画面に残っている可能性があります。
- 対処: 表示されている選択肢どおりに入力し直してください。改善しない場合は `/clear` で会話をリセットしてください。
