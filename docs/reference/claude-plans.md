# Claude 契約プランと管理機能一覧

`🟡 事務・管理`

本書は、ライセンス管理・請求を担当する方向けに、Claude の契約プランと管理機能を記載します。プランには「個人向け(Free / Pro / Max)」と「法人向け(Team / Enterprise)」の2系統があります。当社では、Team / Enterprise での運用は未定です。分からない用語は[用語集](../glossary.md)へ。

## プラン一覧

| プラン | 系統 | Claude Code | 中央管理機能 |
| --- | --- | --- | --- |
| Free | 個人・無料 | 利用不可 | なし |
| Pro | 個人・有料 | 利用可 | なし(本人が自己管理) |
| Max(5x / 20x) | 個人・有料 | 利用可 | なし(本人が自己管理) |
| Team | 法人 | 全シートで利用可 | シート管理・支出上限・利用分析 |
| Enterprise | 法人 | 全シートで利用可 | Team の機能に加え [SSO](../glossary.md#sso-scim)・[SCIM](../glossary.md#sso-scim)・監査 API |

Max(5x / 20x)は、Pro の5倍または20倍の使用量です。機能は Pro と同じです。Premium シートは、Team の中でも使用量が大きいシートです。

## 当社での位置づけ

| プラン | 位置づけ |
| --- | --- |
| Free | 業務利用は不可([Claude Code](../glossary.md#claude-code) が使えないため) |
| Pro | 少人数での試行フェーズの入口 |
| Max | Pro の上限に頻繁に達するメンバー向け |
| Team | チーム正式導入時の第一候補(最低5シートから) |
| Enterprise | 全社展開・監査要件が発生した段階で検討 |

## 個人向けプランを運用する間の管理

- 個人向けプラン(Pro / Max)には、[管理コンソール](../glossary.md#管理コンソール)や[ダッシュボード](../glossary.md#ダッシュボード)がありません。利用状況・費用は、各メンバーの自己申告と請求明細で把握します。
- 契約は、会社メールアドレスと会社経費で行います。「誰が・どのプランを・いつから」を、総務のライセンス台帳で管理します。私用アカウントでの業務利用は禁止です。
- 退職・異動の際は、解約漏れが起きやすいという弱点があります。台帳に解約チェック欄を設けます。
- Team / Enterprise への移行を判断する材料(人数・利用量・管理要件)は、AI 推進チームがとりまとめます。プランの仕様と価格は変更が早いため、契約を検討する際は、必ず公式サイトの最新情報を確認します。

## CI用アクセストークンの有効期限管理

[CI](../glossary.md#ci-github-actions)(自動テスト環境)用のアクセス[トークン](../glossary.md#トークン)は、`claude setup-token` で発行します。有効期限は1年です。更新時期は、総務のライセンス台帳で管理します。期限切れによる自動処理の停止を防ぐためです。
