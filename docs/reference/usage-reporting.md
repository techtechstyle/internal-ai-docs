# 利用状況の計測と報告

`🟢 全員`

本書は、[Claude Code](../glossary.md#claude-code) の利用状況を計測するツールと、導入効果として報告すべき指標を記載します。対象バージョン: v1.6由来。

> **NOTE:** 本書が扱うアナリティクスダッシュボード・Analytics API・貢献メトリクス・OpenTelemetry 連携は、法人向けプラン(Team / Enterprise)を契約した場合に利用できる機能です。当社は現時点で Team / Enterprise での運用が未定のため、個人向けプラン(Pro / Max)で試行している間は、各メンバーが[セッション](../glossary.md#セッション)内の `/cost` `/stats` `/usage` で利用量を確認し、月次で自己申告する方法で代替します。詳細は[Claude 契約プランと管理機能一覧](claude-plans.md)を参照してください。法人プランの契約が決まり次第、本書の手順をそのまま有効化します。
>
> 個人向けプランは定額制のため、通常は急な費用増が起きにくい仕組みです。ただし、上限超過時の追加課金(API 従量課金等)を有効にしている場合は、請求明細を確認してください。費用の急増が見えた場合は AI 推進チームへ連絡してください。多くの場合、大規模な一括作業(移行作業など)が原因であり、異常ではありません。

## 計測ツール早見表

| ツール | 場所 | 分かること | 主な利用者 |
| --- | --- | --- | --- |
| アナリティクスダッシュボード | `claude.ai/analytics/claude-code` | 日次アクティブ利用者、提案の承認率、Claude Code 経由の PR 数・行数、CSV 出力 | 総務・チームリーダー |
| セッション内コマンド | `/cost` `/stats` `/usage` | いま使っている[トークン](../glossary.md#トークン)量・コスト | 各エンジニア |
| Analytics API | Admin API(無料) | ユーザー×日単位の利用レコード(自動集計向け) | AI 推進チーム |
| OpenTelemetry 連携 | `CLAUDE_CODE_ENABLE_TELEMETRY=1` | リアルタイムのトークン・コストメトリクス(Datadog 等へ) | AI 推進チーム(将来) |

PR 貢献メトリクスの取得には、GitHub アプリの追加設定が必要です。設定は AI 推進チームが行います。

## 「成果」として報告する指標

経営報告・契約更新の判断材料として、次の3指標を四半期ごとに追います。

| 指標 | 意味 |
| --- | --- |
| 週次アクティブ開発者数 | 定着しているか |
| 提案の承認率 | 出力の品質が実用水準か |
| Claude Code が関与した PR 数 | 実際の成果物への貢献 |

> **WARNING:** 数字を読むときは次の2点に注意してください。①ダッシュボードの貢献行数は意図的に控えめな数字(下限値)です。20%以上書き換えられたコードは除外されるなど、確実な分だけをカウントしています。実際の貢献はこれより大きい値です。②Anthropic 公表の生産性向上値(調査時間80%削減など)は同社の自己申告値で、第三者監査は受けていません。社外向け資料に引用する際は「Anthropic 社報告値」と出典を明記してください。生の行数をエンジニアの評価に使うことも不適切です。多いことが良いとは限らないためです。
