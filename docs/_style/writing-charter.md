# 執筆1ページ憲章

これだけ守れば、まず大丈夫です。詳しくは[スタイルガイド](style-guide.md)へ。

## 書く前に(30秒)

1. **型を決める**: 読者は「学んでいる」か「作業している」か。必要なのは「行動」か「知識」か。

   |  | 学習中 | 作業中 |
   | --- | --- | --- |
   | 行動 | tutorial | how-to |
   | 知識 | explanation | reference |

2. `_templates/` の該当テンプレートをコピーして書き始める。
3. **1文書1型。** 混ぜたくなったらリンクで逃がす。

## 文体10原則

1. ですます調で統一する
2. 結論を先に書く(段落の最初の文で言い切る)
3. 一文は60字目安、上限90字(読点3つ超で分割)
4. 一段落一アイデア(2〜4文)
5. 冗長表現を避ける(「することができる」→「できる」)
6. 格助詞(が・の・を・に)を省略しない
7. 二重否定を使わない
8. 能動態で、動作の主体を明示する
9. 「〜と思います」は手順書で禁止
10. 肯定形で書く(するな、ではなく、何をするか)

## 3つの約束(手順書を書く人へ)

- **最初の成功を早く**: tutorial は開始5分以内に「できた!」がある。
- **完了を約束する**: 「次の状態になっていれば完了です」+観測できる状態のチェックリスト。
- **エラーは通常ルート**: 「よくあるエラーと対処」を最低1つ。書けないなら自分で実行していないサイン。

## 困ったら

- 事務・管理の方が読む文書 → カタカナ語に言い換えを併記(「リポジトリ(ファイルの保管場所)」)。
- ルールに従うと変になる → 逸脱してよい。理由を PR に一行書く。
- 分からないこと → 遠慮なく Hide か Claude に聞く。
